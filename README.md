# Educational Video Automation System

> Automated pipeline that turns science topics into educational music videos, uploads to YouTube/TikTok, and optimizes performance. Produces ~1 video/day for [@learningsciencemusic](https://youtube.com/@learningsciencemusic).

## Current State (March 2026)

**Channel**: 200+ published videos since Nov 2025. Automated daily pipeline running on macOS via launchd.

### What's Working
- **Full pipeline**: Topic generation → Research → Lyrics → Music (Suno V5) → Media curation → Video assembly → Multi-format output → YouTube upload → Cross-linking
- **Multi-format output**: Full video (16:9) + 3 Shorts (hook, educational, intro) per topic
- **Lyric-video sync**: Word-level timestamps from Suno API, CLIP-powered visual matching
- **AI clip generation**: fal.ai Kling integration for custom AI-generated clips
- **Weekly optimizer**: Analyzes YouTube Analytics, proposes config changes via Claude
- **Change Guardian**: Validates optimizer recommendations against safety guardrails
- **Auto-retry**: Pipeline retries up to 3x with stage-level resume + auto-debugger
- **Notifications**: SMS alerts on success/failure via notification helper

### Recent Growth Infrastructure (Added March 2026)
- **Optimizer re-enabled** after 13 weeks disabled (broken guardrails fixed)
- **Duration increased** 35s → 50s (43% more watch time, consistent optimizer recommendation)
- **Title optimizer**: Curiosity-gap titles generated by Claude (replaces generic `"Topic (Music Video)"`)
- **Thumbnail generator**: Extracts best video frame + text overlay + logo
- **YouTube tags**: 10-15 topic-relevant tags per video (was zero)
- **Engagement booster**: Auto-posts + pins curiosity-inducing comments
- **Engagement CTA in lyrics**: Every song ends with a call-to-action for comments
- **Tone diversification**: 8 musical tones matched to topic category (was 2 for 200+ videos)
- **Niche focus**: 70% engineering/manufacturing topics (best-performing category)
- **Stricter topic dedup**: Semantic similarity threshold raised, catches near-duplicates
- **A/B test manager**: Create/track experiments with weekly alternation
- **Playlist manager**: Auto-organizes videos into 6 category playlists
- **Comment responder**: AI-generated educational replies to viewer comments
- **Analytics history**: Persistent weekly KPI tracking with subscriber data
- **Privacy fix**: Default changed from "unlisted" to "public"

## Quick Start

```bash
# 1. Setup (one-time)
./setup.sh

# 2. Configure API keys
cp config/config.json.template config/config.json
nano config/config.json  # Add Suno, Pexels, Pixabay, fal.ai keys

# 3. Create a video manually
echo "How laser cutters vaporize metal. Tone: heavy industrial rock" > input/idea.txt
./pipeline.sh --express

# 4. Watch
open outputs/current/full.mp4
```

### Automated Daily Run
The system runs automatically via launchd:
- **Daily** at 9:00 AM CST: `automation/daily_pipeline.sh` (topic → video → upload)
- **Weekly** on Sundays at 10:00 AM CST: `automation/weekly_optimizer.py` (analytics → optimization)

```bash
# Check scheduled jobs
launchctl list | grep learningscience

# View today's log
cat automation/logs/daily_$(date +%Y-%m-%d).log

# View latest optimizer report
ls -t automation/reports/*.md | head -1 | xargs cat
```

## Pipeline Stages

```
Topic Generation → Research → Visual Ranking → Lyrics → Music → AI Clips
     ↓                                                        ↓
  input/idea.txt                                         Media Curation
                                                              ↓
                                                        Video Assembly
                                                              ↓
                                                     Multi-Format Output
                                                              ↓
                                                        Subtitle Gen
                                                              ↓
                                                      YouTube Upload
                                                              ↓
                                                       Cross-Linking
```

| Stage | Script | Output |
|-------|--------|--------|
| 0. Topic Generation | `automation/topic_generator.py` | `input/idea.txt` |
| 1. Research | `agents/1_research.sh` | `research.json` |
| 2. Visual Ranking | `agents/visual_ranker.py` | `visual_rankings.json` |
| 3. Lyrics | `agents/2_lyrics.sh` | `lyrics.json` |
| 3.5 Lyric Sync | `agents/lyric_sync.py` | `phrase_groups.json` |
| 4. Music | `agents/3_compose.py` | `song.mp3` |
| 4.5 AI Clips | `agents/generate_ai_clips.py` | `ai_clips/` |
| 5. Media Curation | `agents/4_curate_media.sh` | `approved_media.json` |
| 6. Video Assembly | `agents/5_assemble_video.py` | `full.mp4`, `short_*.mp4` |
| 7. Subtitles | `agents/subtitle_generator.py` | `subtitles/*.srt` |
| 8. Upload | `upload_to_youtube.sh` | `video_id_*.txt` |
| 9. Cross-Link | `automation/youtube_queue_processor.py` | `upload_results.json` |

### Command-Line Options

```bash
./pipeline.sh [OPTIONS]

Options:
  --express              Auto-approve all media (skip manual review)
  --start=N              Start from stage N (1-9)
  --resume               Resume from latest run
  --resume=TIMESTAMP     Resume from specific run directory

./upload_to_youtube.sh [OPTIONS]
  --run=TIMESTAMP        Upload specific run
  --privacy=STATUS       public, unlisted, private (default: public)
  --channel=HANDLE       Channel handle
```

## Growth & Optimization Tools

### Title Optimizer
```bash
# Generate curiosity-gap title for a topic
python3 agents/title_optimizer.py --topic "How laser cutters vaporize metal"
# Output: "This Beam of Light Cuts Through Steel Like Butter"

# Show all variants with scores
python3 agents/title_optimizer.py --topic "How hash tables work" --variants
```

### Thumbnail Generator
```bash
python3 agents/generate_thumbnail.py \
  --video outputs/current/full.mp4 \
  --title "Laser Cutters" \
  --output thumbnail.jpg \
  --logo learning_science_music_logo_blue_1024x1024.png
```

### Engagement Booster
```bash
# Post + pin a comment on a specific video
python3 automation/engagement_booster.py --video-id VIDEO_ID --topic "Laser Cutters"

# Process all recent uploads
python3 automation/engagement_booster.py --batch

# Dry run (preview without posting)
python3 automation/engagement_booster.py --batch --dry-run
```

### Comment Responder
```bash
# Reply to up to 5 recent comments
python3 automation/comment_responder.py

# Dry run
python3 automation/comment_responder.py --dry-run --max-replies 10
```

### Playlist Manager
```bash
# Auto-organize recent videos into category playlists
python3 automation/playlist_manager.py organize --days 30

# Create all category playlists
python3 automation/playlist_manager.py create-all

# Add a specific video
python3 automation/playlist_manager.py add --video-id VIDEO_ID --title "How Laser Cutters Work"
```

### A/B Test Manager
```bash
# Create an experiment
python3 automation/ab_test_manager.py create \
  --name "Upload Volume Test" \
  --config-key "video_formats.format_mode" \
  --control "full" \
  --treatment "reduced" \
  --weeks 4

# List active experiments
python3 automation/ab_test_manager.py list

# Advance to next week
python3 automation/ab_test_manager.py advance
```

### Weekly Optimizer
```bash
# Run manually
python3 automation/weekly_optimizer.py

# View latest report
ls -t automation/reports/*.md | head -1 | xargs cat

# View optimization history
cat automation/state/optimization_state.json | python3 -m json.tool

# View analytics trends
cat automation/state/analytics_history.json | python3 -m json.tool
```

## Configuration

### Main Config (`config/config.json`)
| Setting | Current Value | Description |
|---------|--------------|-------------|
| `video_settings.duration` | 50 | Video duration in seconds |
| `pipeline_settings.max_media_items` | 20 | Max stock clips per video |
| `youtube.default_privacy` | public | Upload privacy status |
| `video_formats.format_mode` | full | "full" (4 formats) or "reduced" (2 formats) |
| `ai_clips.enabled` | true | Generate AI clips via fal.ai |
| `lyric_sync.enabled` | true | Word-level lyric synchronization |

### Automation Config (`automation/config/automation_config.json`)
| Setting | Current Value | Description |
|---------|--------------|-------------|
| `optimization.enabled` | true | Auto-apply high-confidence changes |
| `optimization.confidence_threshold` | 0.8 | Min confidence for auto-apply |
| `optimization.max_changes_per_week` | 2 | Limit changes per optimizer run |
| `topic_generation.avoid_repeat_days` | 30 | Days before topic can repeat |
